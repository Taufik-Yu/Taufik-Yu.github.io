§02 — ABOUT

A generalist by choice

I studied Computer Science and now work as a Software Engineer at PayRecon, building mobile and backend systems for e-commerce sellers across Southeast Asia. I like owning a product end to end — the screen someone taps, the API that answers it, and the server quietly keeping the lights on.

That habit started with Salahly, a prayer times app I built entirely on my own, and it's carried into everything since — including using AI agents as a genuine part of how I build backends faster, without cutting corners.

Outside of code, I work comfortably across four languages — Malay, English, Chinese, and Tamil — which helps a lot on cross-functional teams with designers, backend engineers, and product managers.
